1. Implementasi Array, Struct (Object Literal), dan Pointer (Reference)
  • ARRAY — daftar produk disimpan pada variabel daftarProduk (lihat komentar 1.1 STRUCT + ARRAY di dalam SCRIPT 1). Array juga dipakai untuk keranjang (daftar belanja) dan daftarProduk hasil filter/sorting.
  • STRUCT (Object Literal) — setiap produk adalah satu object dengan properti wajib: id, nama, harga, kategori, stok, rating (ditambah emoji dan lokasi untuk tampilan kartu).
  • POINTER (Reference) — fungsi yang memanipulasi data by reference:
    • cariProdukById(id) → memakai Array.find() yang mengembalikan referensi ke object di dalam array (bukan salinan).
    • tambahKeKeranjang(keranjangRef, produkRef, jumlah) → parameter berupa referensi, sehingga produkRef.stok yang diubah langsung mengubah stok produk pada daftarProduk.
    • ubahJumlahItem(idProduk, selisih) dan hapusItemKeranjang(idProduk) → mengubah stok & item keranjang lewat referensi object yang sama.
    • hitungUlangSubtotal(keranjangRef) → menghitung ulang subtotal tiap item dengan memutasi object item (by reference) dan mengembalikan total.
    • demoPointer() (tombol Demo Pointer di panel log) → bukti bahwa const penunjuk = objekAsli; bukan menyalin data, tetapi menunjuk object yang sama.
// STRUCT (object literal) di dalam ARRAY
const daftarProduk = [
  { id: 1, nama: 'Laptop ASUS VivoBook 14', harga: 7499000,
    kategori: 'Elektronik', stok: 8, rating: 4.7, emoji: '💻', lokasi: 'Jakarta Pusat' },
  // ... 26 produk lainnya (total 27 produk)
];

// POINTER: perubahan lewat referensi langsung mengubah data asli
const produk = daftarProduk.find((p) => p.id === 1);   // referensi, bukan salinan
produk.stok = produk.stok - 1;                           // stok di daftarProduk ikut berubah
2. Fitur Sorting — letak fungsinya
  • KOMPARATOR (SCRIPT 1) — kumpulan fungsi pembanding: harga naik/turun, nama A-Z/Z-A (memakai localeCompare agar urutan alfabet benar), dan rating tertinggi.
  • urutkanProduk(daftar, opsi, denganLog) — fungsi utama sorting. Data disalin lebih dulu (daftar.slice()) agar urutan array asli tidak rusak, lalu diurutkan dengan Array.prototype.sort(). Jumlah perbandingan dihitung untuk ditampilkan di log.
  • Trigger di UI: dropdown “Urutkan” (#selectUrut) pada toolbar → menampilkan log seperti Sorting by Price Ascending (harga termurah → termahal) ... (27 produk) dan Selesai: Sorting by Price Ascending ... ✔ 98 perbandingan • 0.05 ms. Semua log juga dikirim ke console browser.
const hasil = daftar.slice();                 // salinan array (data asli aman)
hasil.sort((a, b) => a.harga - b.harga);      // ascending: termurah → termahal
3. Fitur Searching — letak fungsinya
  • a. Sequential / Linear Search — cariProdukSequential(daftar, kataKunci, denganLog). Dipakai oleh kotak pencarian di navbar. Mendukung pencarian sebagian kata dan kata kunci lebih dari satu (mis. “laptop asus”) serta ikut mencocokkan nama kategori. Log contoh: Searching for 'laptop' ... (sequential search) lalu Found 1 items (sequential search • 27 perbandingan • 27 data).
  • b. Binary Search — cariProdukBinary(daftar, kataKunci, denganLog). Data diurutkan berdasarkan nama lebih dulu (syarat mutlak binary search), lalu dicari dengan membagi dua ruang pencarian. Butuh nama yang persis sama. Diuji lewat tombol “Jalankan Binary Search” di panel log; log akan menampilkan setiap langkah pembagian data (kiri/kanan/tengah), mis. Langkah 3: kiri=7 • kanan=13 • tengah=10 → "Kopi Arabika Gayo 250 gram" (kunci < data → geser batas kanan), sehingga jumlah perbandingannya terlihat jauh lebih sedikit dibanding sequential search.
  • Trigger di UI: tekan Enter/tombol Cari pada kotak pencarian → hasil ditampilkan pada grid + log pencarian muncul di panel log dan console.
// Sequential search: memeriksa data satu per satu (untuk 27 produk = maksimal 27 perbandingan)
// Binary search    : maksimal ±log2(27) ≈ 5 perbandingan, tetapi nama harus persis
4. Cara menjalankan file
  • Cara termudah: simpan file e-pasar.html, lalu klik dua kali (double click) file tersebut sehingga terbuka di browser (Chrome/Edge/Firefox). Tidak perlu instalasi apa pun, karena CSS & JavaScript sudah menyatu di dalam file ini (tanpa CDN/internet).
  • Via Visual Studio Code: buka file e-pasar.html, klik kanan → Open with Live Server (bila ekstensi Live Server terpasang), atau Open with Default Browser.
  • Melihat log: buka DevTools browser dengan F12 → tab Console, lalu lakukan pencarian/sorting. Log yang sama juga tampil pada panel “Log Aktivitas” di bagian bawah halaman.
  • Tampilan & ikon: seluruh ikon antarmuka (kaca pembesar, keranjang, tombol tutup, ikon urutkan, plus/minus, hapus, bintang rating, penunjuk lokasi, dsb.) memakai ikon SVG bergaya garis (stroke) yang didefinisikan sekali dalam sprite <symbol> di bagian atas <body>, lalu dipanggil dengan <use href="#ikon-..."></use> melalui helper ikonSvg() di bagian JavaScript tampilan. Ikon memakai stroke="currentColor" sehingga otomatis mengikuti warna teks/tombol dan tetap tajam di segala ukuran layar (retina/HiDPI); emoji hanya dipakai sebagai gambar produk pada kartu. Logo toko (#ikon-logo) dan ikon keranjang (#ikon-keranjang) sengaja dibuat sebagai dua ikon yang berbeda, sedangkan ikon tas (#ikon-tas) khusus dipakai tombol Beli pada kartu produk. Jadi tampilan tetap minimalis dan tidak bergantung pada file gambar atau CDN.
  • Cara mencoba fitur:
    • Ketik laptop di kotak pencarian lalu tekan Enter → lihat log searching.
    • Pilih Harga: Termurah pada dropdown Urutkan → lihat log sorting.
    • Klik Beli beberapa kali → stok berkurang (perubahan via referensi) dan keranjang bertambah.
    • Klik Demo Pointer → membuktikan object dioper by reference.
